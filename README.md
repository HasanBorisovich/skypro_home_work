# Обработка транзакций

## Описание
Этот проект содержит функции для фильтрации и сортировки списка транзакций по различным критериям, таким как состояние и дата. Он помогает удобно управлять данными о финансовых операциях.

## Цель проекта
Обеспечить быстрый и удобный способ обработки списка транзакций, что полезно для аналитики, отчетов или автоматизации процессов.

## Установка
Этот проект не требует дополнительных зависимостей, кроме стандартной библиотеки Python. Просто скопируйте функции и используйте их в своем проекте.

## Использование
Примеры использования функций:

from processing import filter_by_state, sort_by_date

transactions = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2021-07-01T10:00:00'},
    {'id': 2, 'state': 'CANCELED', 'date': '2021-06-30T09:00:00'},
    {'id': 3, 'state': 'EXECUTED', 'date': '2021-07-02T11:00:00'},
]

 Фильтрация по состоянию 'EXECUTED'
executed_transactions = filter_by_state(transactions, 'EXECUTED')

 Сортировка по дате (по убыванию)
sorted_transactions = sort_by_date(transactions)

## Примеры работы:

Входные данные:
transactions = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2021-07-01T10:00:00'},
    {'id': 2, 'state': 'CANCELED', 'date': '2021-06-30T09:00:00'},
]

Выходные данные:

Результат фильтрации (по состоянию):
[{'id': 1, 'state': 'EXECUTED', 'date': '2021-07-01T10:00:00'}]

Результат сортировки (по дате):
[{'id': 1, 'state': 'EXECUTED', 'date': '2021-07-01T10:00:00'},
 {'id': 2, 'state': 'CANCELED', 'date': '2021-06-30T09:00:00'}]
